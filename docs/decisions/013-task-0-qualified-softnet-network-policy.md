# ADR 013: Qualify the Tart + Softnet network policy before freezing launch argv

Status: Superseded by ADR 015

ADR 003 is superseded because Softnet's default gateway allowance permits guest-initiated traffic to the trusted macOS host. Boxwarden's backend-independent property is that a session may reach the public Internet and receive required host-to-guest management SSH, but cannot initiate connections to the trusted host, private networks, or any concurrent Boxwarden session. The expected M1A mechanism is Softnet with an explicit host block; `--net-softnet-block=@host` is the primary candidate, with a resolved gateway `/32` as the fallback candidate if Tart does not forward the alias. Task 0 must qualify the exact Tart + Softnet versions and provenance, prove the syntax and resulting traffic behavior, and verify DHCP, DNS, address discovery, and lease renewal before exact launch argv is frozen. `--net-softnet-allow=0.0.0.0/0` is prohibited in M1A because current Softnet semantics also disable bridge isolation. Future network exceptions or guest-agent bridges require separate architecture review because they change the host↔guest or session↔session trust surface.
