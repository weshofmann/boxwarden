## Single-window sequence

1. **Preflight once.** Verify all hashes, source reviews, exact host pair,
   stock doctor, capacity/storage, fresh R1 configs and task-only names. Record
   protected VM small-file hashes/disk metadata and workspace record hashes/raw
   metadata without reading private keys or hashing large disks. Confirm old
   failed evidence remains untouched. Review sibling phases before the expensive
   boundary; propagate any new constraint to every unexecuted phase.
2. **Attended exact admission.** Owner executes the separately reviewed
   installation for only the new diagnostic candidate. Abort on any ambiguous
   tree, consumer or manifest. Do not repair/rebind stock or mutable Homebrew.
3. **Two fresh guests only.** Create stock control and diagnostic candidate from
   the same admitted base, no workspace/credentials. Obtain READY and public
   stop/start if exact clone-only staging is required; discard previous pins and
   certificates. Review concrete staging only after UUID/backend/generation
   exist. Verify actual installed bytes and root ownership/modes, exact active
   desktop/Xwayland binding, and diagnostic paths/coverage before any write.
4. **Stock clipboard positive.** Through the bound public CLI, one fixed benign
   synthetic copy and one exact readback. Trace metadata covers the same path;
   a failed stock control invalidates the clipboard comparison. Output goes to
   a bounded memory buffer, never the Mac pasteboard. Save equality/length/hash
   and stage codes only. Unknown copy is not retried.
5. **Candidate clipboard interval.** One synthetic copy, then the first single
   readback immediately, while owner native selection and exact PID/birth
   metadata are observed. Collect both operation traces and trusted-host stage
   receipts even on failure. Never issue another text retrieval to diagnose it.
   TARGETS and owner metadata queries are separately bounded observations, not
   a second payload read. Missing/perturbed observations stay incomplete.
6. **Peer TCP interval.** Bind current pair addresses/IDs/generations and exact
   Softnet process/sink. Arm complete finite guest counters and actual N1 seam
   counters **before** the probe; record one-target route/neighbor snapshots.
   Strict host SSH22 positive to stock immediately before; one candidate socket
   connect to that exact endpoint, timeout <=4 seconds, no authentication,
   credentials or banner payload request; strict same-generation host positive
   immediately after. Record connected/error/timeout plus socket phase/errno,
   elapsed offsets, READY/management/gateway DNS/public HTTPS controls. Close
   observers and collect their completeness/drop counts and post metadata.
   Do not flush a preexisting neighbor: report that route/neighbor topology and
   evaluate only the emitted path. No emission is evidence only with complete
   coverage; a full-length vmnet API return with no reply leaves enqueue and internal
   cause open.
7. **Stop, collect, retire.** Publicly stop/reap/delete only the exact new pair;
   no restart/rebuild/retry. Save immutable private receipts to the approved
   durable archive and verify readable hashes/provenance. Owner executes newly
   approved exact candidate cleanup after all consumer checks. Verify candidate
   absence, unchanged stock manifest/tools and healthy stock doctor using a
   non-retired diagnostic config, and matching protected inventories. Retire
   only new task-owned state. On cleanup ambiguity contain and preserve evidence.

## Expected adjudication

Clipboard exact readback closes delivery for that tested path; a traced failure
localizes it without changing the old UNQUALIFIED row. Diagnostic perturbation,
missing owner/target/binding evidence or host stages leaves a bounded open cause.

Cross-guest connect is FAIL even if later transport fails. Preserve the existing
TCP verdict rules: errno113 is UNQUALIFIED, not a manufactured timeout PASS.
Observed exact peer ARP ingress + actual policy denial + no write attributes
that denial for this new interval; no-return after a full-length vmnet API return cannot establish enqueue
or identify vmnet internals. Missing host positives makes the check INVALID. Record new
results separately, including unattributed branches and observer blind spots.

No gateway listener repeat, UDP peer test, VPN/DNS/firewall/route/neighbor change,
Ubuntu rebuild or existing guest/workspace operation belongs to this window.
One window can answer both questions when the required events occur; no design
can guarantee an intermittent failure reproduces or that passive silence proves
an internal cause. Never promise a clean verdict in advance.
